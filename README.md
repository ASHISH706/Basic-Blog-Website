# Basic Blog Website

A simple and functional **Blog Website** built using **Node.js**, **EJS templates**, and CSS.  
This project allows users to view blog posts with a clean UI — perfect as a starter full-stack web project.

## 🧠 Project Overview

This is a basic blog web application that demonstrates how to serve dynamic pages using Node.js and EJS. It includes routing for different pages and styles with CSS. Great for beginners learning how to build and deploy web apps.

## 📋 Features

✔ Dynamic blog pages using EJS templates  
✔ Easy to understand project structure  
✔ CSS styling for layout and responsiveness  
✔ Simple file-based content rendering

## 📂 Technologies Used

- **Node.js** – Backend runtime  
- **Express.js** – Web framework  
- **EJS** – Template engine  
- **CSS** – Styling  
- **JavaScript** – App logic
